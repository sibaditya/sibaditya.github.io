# Sibaditya Maiti — Portfolio

Personal portfolio site for Sibaditya Maiti: Android enthusiast and entrepreneur, founder of [Hazelcrow](https://hazelcrow.com).

Live at **https://sibaditya.github.io**

## What's on the site

- **About** and **Experience** (Bell Canada, Flipp, BlackBerry Messenger, Paytm, Aspiring Minds, Samsung Research Institute)
- **What I Do**: mobile apps, Kotlin Multiplatform, websites, launch and monetization, technical leadership, AI-assisted delivery
- **Projects**: [Docsmith](https://hazelcrow.com/docsmith/), [Satsang Canada](https://satsangcanada.com) and [Hazelcrow](https://hazelcrow.com)
- **Skills**, **Education** and **Contact**

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | The whole site: markup, styles and a small script, with no build step |
| `photo.jpg` | Profile photo |
| `resume.pdf` | Downloadable resume |

## Run locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Hosted on GitHub Pages from the `main` branch. Pushing to `main` publishes the site.
